# jseward.com

Personal academic website for Jonathan A. Seward, Senior Research Scientist & Lecturer in Economics at Baylor University.

## Technology

Pure HTML5, CSS3, and vanilla JavaScript. No frameworks or build tools. Hosted on GitHub Pages with a custom domain.

## Local Development

Open `index.html` directly in a browser, or run a local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Deployment

Push to `main` branch. GitHub Pages auto-deploys from root.
